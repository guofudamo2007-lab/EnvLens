# 使用 EnvLens 排查问题

[English](USAGE.md) · [返回首页](../README.md)

## 先选对环境

默认选择顺序为活动 venv、活动 Conda、PATH、Launcher、Conda 用户登记表。相同路径会合并并列出发现来源。在 **Python 环境** 选择一个候选项，或者直接选择本地解释器。文件选择支持常见的 `python.exe`、`python3.exe` 和带版本的 Python 可执行文件。

选择项目目录会将搜索限制在根目录、`.venv`、`venv`、`env` 和便携 Python 约定位置。目录中没有解释器时，系统与 GPU 仍可检查，Python 和 PyTorch 会标为未检查。外置环境请直接选择解释器。页面分别显示下次体检目标与当前报告记录的解释器，修改目标后需要重新体检。

## 阅读结果

| 状态 | 含义 |
| --- | --- |
| 正常 | 该项观测或操作成功，适用范围见证据 |
| 警告 | 证据显示可能影响当前工作流，值得核对 |
| 异常 | 指定操作失败，或发现了明确的运行障碍 |
| 未检查 | 缺少前置条件、组件可选，或用户没有启用该项 |
| 无法确定 | 权限、超时、输出限制、协议或证据不足导致结论不完整 |

确认的事实与可能的根因会分别显示。驱动查询成功只证明工具能与驱动通信。PyTorch 的构建版本、设备枚举、张量运算分别列项。CUDA 系列最低驱动仅用于识别明显不兼容的情况，超过该下限仍可能存在设备架构或特性限制。[NVIDIA 兼容性说明](https://docs.nvidia.com/deploy/cuda-compatibility/latest/minor-version-compatibility.html)

## Windows 看到显卡时如何排查项目仍在使用 CPU

1. 打开 **GPU / CUDA**，核对驱动行中的 GPU 型号及驱动版本。
2. 对照 **报告中的解释器** 和项目的启动命令。若当前检查的是其他 Python，先切换解释器再复检。
3. 查看 PyTorch 证据。如果已发现 NVIDIA 设备，而 `torch.version.cuda` 为 `None`，可以确认这个构建缺少 CUDA 支持。需要 GPU 加速的用户可按官方选择器选择适配的构建，在目标环境中自行安装。[PyTorch 官方安装页](https://pytorch.org/get-started/locally/)
4. 在设置启用 **单元素 GPU 验算**。复检时看 `torch.cuda.is_available`、设备名称及 `result = 2`。验算仅针对第一张 CUDA 设备。CUDA 初始化本身可能分配运行时显存。

## 报告与隐私

**复制摘要** 会复制状态统计及主要问题。**导出报告** 可以选择 Markdown、JSON 或 HTML。默认隐藏解释器、安装目录、项目路径和模型名称。关闭脱敏时预览会显示原始路径。JSON 保留结构化证据及中英文解释，HTML 在浏览器中离线可读。软件仅显示修复建议，所有命令由用户自行决定是否执行。

历史保存在 `%LOCALAPPDATA%\dev.envlens.localdiagnostics\history-v1\`，默认保留最近 20 份已脱敏报告。重启后可以继续查看，打开历史报告无法恢复原始路径。**比较状态** 按稳定检查 ID 对比两份报告的状态，详细版本差异可查看 JSON。用于分享截图时，在设置中启用 **隐藏屏幕上的个人路径**。

## 支持边界

- 首版深入检查 CPython 3.8 及以上。旧版或无法启动的解释器会留下探针失败记录。可见范围遵循受控发现来源，没有全盘扫描。
- 探针使用隔离模式并显式加载环境里的包目录，项目脚本、`.pth` 启动代码和定制启动钩子不会运行。通过这些机制加载的可编辑安装、特殊嵌入式发行版或定制 Conda DLL 路径可能需要在项目自己的终端交叉验证。请选择信任的解释器和已安装组件。PyTorch 探针需要实际导入该环境的 PyTorch。
- 驱动工具和包检查有超时及输出上限。权限不足与探针无结果分别标明。硬件或软件未被当前来源观察到时，应结合其他证据核对。
- Ollama 只读取 `127.0.0.1:11434/api/version` 和 `/api/tags`。清单最多展示 40 个名称，保留清单总数。模型推理持续标为未检查。[Ollama 模型列表](https://docs.ollama.com/api/tags)
- 当前安装包未做 Authenticode 签名。首次构建或安装缺失的 WebView2 时可能需要联网获取开发依赖或运行时。
